## 应龙产品五层架构图（对话内可视化）

按用户口述绘制了应龙产品的分层架构图（内联 SVG，未落盘文件）：

- 自下而上：接入层 → 平台层 → 数据层 → 服务层 → 应用层
- 接入层：GPU/NPU 异构算力服务器（NVIDIA A100/A800、昇腾 910B3）+ Kubernetes 集群（v1.26–v1.29），通过「集群注册 / 节点纳管」接入平台
- 平台层（本产品所处层次，图中高亮为蓝色）：算力调度、任务管理、模型管理、资源与运维四大能力，向上屏蔽异构算力与容器部署细节
- 数据层：共享存储（模型包路径 /data/yl/modelPath、部署配置）+ 平台数据库（任务、服务、申请、日志）
- 服务层：模型服务实例（在线服务 / 离线批处理），容器化运行于集群节点，统一接口对外调用
- 应用层：各业务系统以任务级 API Key 调用平台模型服务接口
