# 2026-11-24 Docker 主机纳管 - 原型落地

## 背景
新项目现场无 K8s、习惯 Docker 部署。产品决策：支持「同时纳管 K8s 集群 + Docker 主机」混部形态，平台核心不感知运行时，通过统一 Runtime 接口 + K8s/Docker 两套适配器实现；每台主机装 yl-agent（Go 单二进制、systemd 托管、挂载 docker.sock、gRPC 外拨 + mTLS）。
