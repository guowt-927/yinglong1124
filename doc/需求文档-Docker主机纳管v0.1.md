## 1. 背景与目标

### 1.1 背景

平台当前基于 K8s 架构，所有模型服务均以 Pod 形态调度。新项目现场存在以下差异化需求：

- 现场缺失 K8s 环境，运维习惯为 Docker 直接部署；
- 业务不允许停服，迁移成本敏感；
- 现有 Docker 容器需原样保留，不能因纳管而重建。

### 1.2 目标

在**不改动客户现有环境**的前提下，新增「Docker 主机」作为与 K8s 集群并列的运行环境，实现：

1. 模型服务可以 Docker 容器形态部署到指定主机，并执行启动 / 停止 / 删除；
2. 工作台与监测、集群与主机、主机详情、部署弹窗、服务列表五个页面同步展示两种运行环境。

---

## 2. 核心概念

| 概念 | 说明 |
| --- | --- |
| 运行环境（Runtime） | K8s 集群 或 Docker 主机；平台核心不感知运行时，通过统一 Runtime 接口 + K8s / Docker 适配器实现 |
| yl-agent | 部署在 Docker 主机上的轻量代理，负责部署、启停、状态上报、GPU 挂载 |
| 轻纳管 | Docker 主机仅做连通、纳管、监控与实例启停，不承诺环境改造与全生命周期管理 |

## 5. 需求详情

### 5.1 工作台与监测

#### 5.1.1 页面说明

- 页面位置：工作台 > 系统概览。

#### 5.1.2 核心业务逻辑

1. 显卡资源区新增「运行环境」下拉（全部 / K8s 集群 / Docker 主机），与「集群 / 主机」下拉联动：选 Docker 时只显示主机，选 K8s 时只显示集群。
2. 显卡资源表格新增「运行环境」列。
3. 「在线节点」指标下方拆分展示 K8s 节点数 / Docker 主机数。
4. 「预警规则配置」旁新增「历史预警」入口，弹窗为纯列表 + 分页，无筛选、无搜索。
5. 预警体系只覆盖 K8s 集群，不新增 Docker 主机类预警。

---

### 5.2 集群与主机

#### 5.2.1 页面说明

- 页面位置：资源与运维 > 集群与主机。
- 操作人：管理员（一级）。

#### 5.2.2 核心业务逻辑

1. 页面通过「K8s 集群 / Docker 主机」两个 Tab 切换面板，Tab 上显示计数。
2. Docker 主机面板展示主机数、加速卡（已用 / 总数）、运行实例三项概览指标。
3. 主机列表不提供筛选、搜索、批量操作，每行仅提供「详情」入口。
4. 页头按钮按当前 Tab 打开对应弹窗：K8s 面板为「新建集群」（账号密码 / 配置文件两种方式），Docker 面板为「注册 Docker 主机」（仅 IP、名称、SSH 端口 / 账号 / 密码）。
6. 移除主机需二次确认；主机仍有运行实例时阻止移除。

#### 5.2.3 操作验证规则

| 按钮/操作 | 前置条件       | 后置结果           | 异常与提示                               |
| --------- | -------------- | ------------------ | ---------------------------------------- |
| 移除主机  | 主机无运行实例 | 从列表移除并 toast | 有运行实例时提示「请先停止或迁移」并阻止 |

---

### 5.3 主机详情

#### 5.3.1 页面说明

- 页面位置：资源与运维 > 集群与主机 > 主机详情。
- 通过 URL 参数复用 K8s 节点详情页进入 Docker 模式。

#### 5.3.2 核心业务逻辑

1. Docker 模式下仅保留「实例运行情况」一个 Tab。
2. 页面展示主机加速卡型号、GPU 容量、GPU 利用率、显存占用率等概览信息。
3. 实例列表为纯展示，不提供任何操作；实例的启停、删除统一在「模型服务」列表执行。

---

### 5.4 部署弹窗

#### 5.4.1 页面说明

- 入口：模型服务列表 > 部署服务；或服务行 > 编辑（已停止服务）。

#### 5.4.2 核心业务逻辑

1. 部署位置为两级选择：先选「部署运行环境」（K8s 集群 / Docker 主机），再选「部署目标」。
2. 选择 Docker 时展示能力差异提示：不经过 K8s 调度、不跨主机重调度、不在线扩缩容；加速卡由平台自动分配。
3. 展示实例上限提示；当所需卡数超过主机空闲卡时红字提示并阻止提交。
4. 提交后依次执行 拉取镜像 → 创建容器 → 健康检查 三步进度。
5. 编辑模式仅对已停止的 Docker 服务开放，提交后提示「配置已更新，重启实例后生效」。

#### 5.4.3 操作验证规则

| 按钮/操作           | 前置条件      | 后置结果                                 | 异常与提示             |
| ------------------- | ------------- | ---------------------------------------- | ---------------------- |
| 切换部署运行环境    | --            | 刷新目标下拉、显隐说明条与上限提示       | --                     |
| 提交（Docker 部署） | 卡数 ≤ 空闲卡 | 关闭弹窗                                 | 超限时滚动至提示并阻止 |
| 提交（Docker 编辑） | 服务已停止    | 关闭弹窗，「配置已更新，重启实例后生效」 | --                     |

---

### 5.5 服务列表

#### 5.5.1 页面说明

- 页面位置：模型管理 > 模型服务。

#### 5.5.2 核心业务逻辑

1. 列表新增「运行环境」列与「运行环境」筛选。
2. Docker 服务操作按状态收口：运行中仅显示「停止」；已停止显示「删除 / 编辑 / 启动」。
3. 停止 Docker 服务需二次确认，停止后提示「容器已停止，所占加速卡已释放」。

#### 5.5.3 操作矩阵

| 服务状态 | 运行环境   | 操作按钮     |
| ---- | ------ | -------- |
| 运行中  | K8s    | 扩缩容、停止   |
| 运行中  | Docker | 停止       |
| 已停止  | K8s    | 删除、编辑、启动 |
| 已停止  | Docker | 删除、编辑、启动 |

#### 5.5.4 操作验证规则

| 按钮/操作      | 前置条件  | 后置结果                          | 异常与提示       |
| ---------- | ----- | ----------------------------- | ----------- |
| 停止（Docker） | 服务运行中 | 二次确认后停止，toast「容器已停止，所占加速卡已释放」 | --          |
| 编辑（Docker） | 服务已停止 | 打开部署弹窗（configure 模式）          | 运行中不展示编辑入口  |
| 启动（Docker） | 服务已停止 | 二次确认后启动，实例回到运行中               | 所需卡不足时阻止并提示 |
